# Plan - Key for the Box

## Goal
Ship a free offline box for kids, families, and seniors. The lid opens only after the key is in, and the key stays in while the lid is up.

## Approach
1. Write one Expo screen and the box rules.
2. Check the rules, then commit and push before the simulator run.
3. Build a Release binary and run the full simulator regression.
4. After every check passes, take three screenshots and submit build 1.
